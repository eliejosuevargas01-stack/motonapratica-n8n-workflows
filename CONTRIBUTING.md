# 🤝 Contribuindo com Moto Na Pratica - N8N Workflows

Obrigado pelo interesse em contribuir! Este documento fornece diretrizes para contribuir com o projeto.

## 📝 Como Contribuir

### 1. Reportando Issues

- Use o template de issue
- Descreva o workflow afetado
- Inclua logs de erro
- Forneça passos para reproduzir

### 2. Propondo Melhorias

- Abra uma issue primeiro para discutir
- Explique o problema ou melhoria
- Proponha uma solução

### 3. Enviando Pull Requests

1. Fork o repositório
2. Crie uma branch: `git checkout -b feature/minha-melhoria`
3. Faça commit das mudanças: `git commit -m 'Adiciona melhoria'`
4. Push: `git push origin feature/minha-melhoria`
5. Abra um Pull Request

## 🔄 Padrões de Workflow

### Nomenclatura

- Use nomes descritivos: `Moto Na Pratica - [Função]`
- Tags: Sempre use `Moto-Na-Pratica`

### Documentação

- Todo workflow deve ter documentação em `/docs/workflows/`
- Inclua diagrama de fluxo
- Descreva inputs e outputs
- Liste credenciais necessárias

### Testes

- Teste o workflow antes de submeter
- Documente casos de uso
- Inclua dados de teste

## 🏷️ Tags

| Tag | Significado |
|-----|-------------|
| `Moto-Na-Pratica` | Workflow do projeto |
| `deprecated` | Workflow obsoleto |
| `beta` | Em testes |

## 📝 Commits

Use conventional commits:

- `feat: adiciona novo workflow`
- `fix: corrige bug no scrapper`
- `docs: atualiza documentação`
- `refactor: otimiza performance`

## ⚖️ Código de Conduta

- Seja respeitoso
- Aceite críticas construtivas
- Foque no que é melhor para a comunidade

## 📞 Contato

Para dúvidas, abra uma issue ou entre em contato.
